One funny line for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun: a single sentence of at most 200 characters, judged head-to-head for the bigger laugh.

`main.py` (Python 3.13, standard library only) copies `line.txt` byte for byte to `/output/entry.txt`, after checking the gate: UTF-8, 1–200 characters, not only white space, a single line.

## The line

> I downloaded a meditation app to relax, and now I lie awake stressing about my 47-day streak.

## Run

```sh
python3 main.py
```
